# まもなく、魔改造電車が参ります

開発コード: **hakobi**　／　遊ぶ: https://qnaiv.github.io/traintrain/

急ブレーキの慣性で屋根の乗客を駅のホームへ射出して届ける、リアルタイムの鉄道ローグライク（ブラウザ・スマホ縦向け）。

## 遊び方

- 駅で乗せる客を選ぶ。客ごとに運賃（コイン1〜5）と耐えられる衝撃が違う
- 走行中は障害を突破する：倒木は速く、急カーブは遅く、鹿はタップ、電柱は連打
- 駅の手前で **急ブレーキ射出**（Space）。耐えられない客が前へ飛ぶ。点線が着地予測
  - ホームに着地で GOOD、×2マットなら PERFECT（運賃2倍）。駅ごとに連続で決めると上乗せ
  - 速すぎると車内の客まで飛ぶ。席・つり革・屋根の配置とビルドで「誰が飛ぶか」を企む
- 停車すると駅のお店でアイテムや魔改造を買える（射出で通過するとお店には寄れない）
- 終点で稼ぎの一部を持ち帰り、車両基地で「持ち込み改造」を解放。出発前に1つ選ぶ
- 遅れが上限を超えるか、信頼0で運転打ち切り

| 操作 | タッチ | キーボード |
| --- | --- | --- |
| 加減速 | 下のレバー | — |
| 急ブレーキ射出 | 左下のボタン | Space |
| バック（オーバーラン時） | 長押しボタン | B |
| ズーム | ピンチ | ホイール |

## 開発

```sh
npm install
npm run dev      # 開発サーバー
npm run build    # 型チェック＋ビルド（dist/）
```

確認用のURLパラメータ：`?debug`（`__R()` で状態、`__S` で関数）、`?go`（車両基地をとばして出発）、`?speed=2`（早回し）

## 構成

- `src/game/state.ts` … ルール・状態・更新（DOMに依存しない）。客、障害、射出の物理、お店、持ち込み改造
- `src/game/draw.ts` … 外（台座ジオラマ・射出の予測・着地）と車内の描画
- `src/game/main.ts` … 入力・HUD・お店・車両基地・画面遷移
- `src/game/audio.ts` … Web Audio で合成した BGM と効果音
- `src/exterior.ts` / `src/iso.ts` / `src/people.ts` … 台座ジオラマ、クォータービューの投影、人形

旧版と試作（参考として残している）：`legacy.html`（v0.3 の停車ゲーム）、`shake.html`（満員電車シェイク）、`launch.html`（射出の単体試作）。`run.html` はトップへの転送。
