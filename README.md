# まもなく、魔改造電車が参ります

開発コード: **hakobi**

実在の路線を、魔改造した列車で時刻表と競いながら走りきるブラウザ向けローグライク。

## いまできること（v0.1・最低限動く版）

- 江ノ島電鉄（藤沢 → 鎌倉、15駅）を1本走れる
- 走行中はブレーキ長押しで停止位置に止める（ぴったり／良／手前／オーバーラン判定）
- 停車中も時計は進む。ドアを開けて乗降、発車ボタンで発車（ドアが開いていれば閉めてから発車）
- 乗り切れない客は積み残し、ホームからはみ出した車両はドアカット
- 遅れ5分か信頼0で運転打ち切り、終点で全員降ろせばクリア
- 駅を出るたびに強化を3択。上限なしで重ねがけできる

## 操作

| 操作 | タッチ | キーボード |
| --- | --- | --- |
| ブレーキ | ブレーキボタンを長押し | Space（押している間） |
| ドア開閉 | ドアボタン | D |
| 発車 | 発車ボタン | Enter |
| 強化を選ぶ | カードをタップ | 1 / 2 / 3 |

## 開発

```sh
npm install
npm run dev      # 開発サーバー
npm run build    # 型チェック＋ビルド（dist/）
npm run sim      # ボットに走らせてバランスを確認
```

確認用のURLパラメータ:

- `?speed=4` … 時間を早回し
- `?cars=12&doors=8` … 魔改造済みの編成から始める

## 構成

- `src/data.ts` … 路線データ（ホーム長・需要・駅間距離はゲーム用の仮の値）
- `src/game.ts` … ゲームの状態と更新（DOMに依存しない）
- `src/upgrades.ts` … 強化の定義と3択の抽選
- `src/render.ts` … キャンバス描画（横から見た図）
- `src/main.ts` … 入力・HUD・画面遷移
