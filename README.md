# まもなく、魔改造電車が参ります

開発コード: **hakobi**

実在の路線を、魔改造した列車で時刻表と競いながら走りきるブラウザ向けローグライク。

## いまできること（v0.3）

- 江ノ島電鉄（藤沢 → 鎌倉）を1本走れる。テンポ優先で実際の15駅を7駅に間引いている
- 走行中はブレーキ長押しで停止位置に止める（ぴったり／良／手前／オーバーラン判定）
- 停車中も時計は進む。ドアは着いたら自動で開き、発車ボタンで閉めて発車
- 乗り切れない客は積み残し、ホームからはみ出した車両はドアカット
- 遅れ5分か信頼0で運転打ち切り、終点で全員降ろせばクリア
- 駅を出るたびに強化を3択。上限なしで重ねがけできる
- 外の視点は、一定の大きさの台座の上を景色が流れるジオラマ。編成が長くなるほど引いて全部の車両を見せる
- 乗客は1人ずつ行き先と席を持つ。ドアの開かない車両にいる客は通り抜けで遅く、降りそびれると信頼が減る
- 画面下の編成バーで、各車両の混み具合と次で降りる人数を確認できる

## 操作

| 操作 | タッチ | キーボード |
| --- | --- | --- |
| ブレーキ | ブレーキボタンを長押し | Space（押している間） |
| 発車 | 発車ボタン | Enter |
| 強化を選ぶ | カードをタップ | 1 / 2 / 3 |

## 開発

```sh
npm install
npm run dev      # 開発サーバー
npm run build    # 型チェック＋ビルド（dist/）
npm run sim      # ボットに走らせてバランスを確認
```

確認用のURLパラメータ:

- `?speed=4` … 時間を早回し
- `?cars=12&doors=8` … 魔改造済みの編成から始める

## 構成

- `src/data.ts` … 路線データ（ホーム長・需要・駅間距離はゲーム用の仮の値）
- `src/game.ts` … ゲームの状態と更新（DOMに依存しない）
- `src/upgrades.ts` … 強化の定義と3択の抽選
- `src/render.ts` … 描画のまとめ役
- `src/exterior.ts` … 外の視点（台座と流れる景色、電車）
- `src/iso.ts` … クォータービューの投影と描画の土台
- `src/people.ts` … 人形の描画
- `src/seats.ts` … 車内の席の並び
- `src/panels.ts` … キャンバス上部の路線ストリップ・停止メーター・停車パネル
- `src/main.ts` … 入力・HUD・画面遷移
